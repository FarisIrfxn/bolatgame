# Pokélove Adventure: notes for AI agents

- Start with `GAME_VISION.md` (the whole design, decisions and progress log, in Malay).
- Changing how a zone/map looks (props, ground, textures, 3D models, lighting, colliders around props):
  follow `docs/ZONE_ART_GUIDE.md`. Labu Lanjut is the reference zone.
- Asset generation (local ComfyUI on port 8188, images, textures, 3D): `pipeline/README.md`.
- Game code and how to run it: `game/README.md`. Dev server port 5181; the public tunnel serves the
  production build on 5180.
